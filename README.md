## Overview

Splitter is a minimal, fast speedrun timer supporting split files, best-segment tracking, gold splits, comparison columns, and hotkey configuration without the complexity of full-featured alternatives.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Splitter Speedrun Timer** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Segment Tracking** | Gold, personal-best, and current-pace columns per split |
| **Split File Format** | Compatible with standard .lss and custom JSON split formats |
| **Hotkey Manager** | Global hotkeys for start, split, reset, and undo with conflict detection |
| **Comparison Modes** | Toggle between PB, best segments, average, and balanced pace |
